## 1. What the bar asks

ROADMAP §13 accepts the first production vertical on two consecutive complete passes:

```text
KM통상 CONNECT → real product COLLECT → canonical PRODUCT DB → SmartStore REGISTER
→ marketplace READ-BACK → OPERATE state sync → fulfillment record/tracking path when an order exists
```

It also lists, for any vertical:
- the UI action reaches its service, through the canonical contract;
- the real write happens where permitted;
- the result is read back, the canonical DB reflects it, and the UI reflects it after a reload;
- the same flow succeeds again in a fresh session;
- nothing unrelated regresses.

Rule 12 places this at the final first-vertical closeout, on the final implementation line-up.
