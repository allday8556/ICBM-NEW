## 3. UI source rule

The approved standalone HTML prototype recorded in `documents/contracts/ui/UI_SOURCE_OF_TRUTH.md` is the visual/product shell.

Use it for:

- visual hierarchy
- navigation
- responsive layout
- labels/status surfaces
- modal/drawer/empty-state interaction shapes

Do not treat its demo data, mock counts, or prototype JavaScript as runtime business truth.
