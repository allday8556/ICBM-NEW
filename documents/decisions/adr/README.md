# Architecture Decision Records

Accepted architecture decisions live here as numbered ADRs; later changes require a superseding ADR instead of silent edits. An explicit, attributed amendment note that states its authority and preserves the amended text — the form ADR-0017, ADR-0019 and ADR-0020 use on the ADRs they amend — is not a silent edit.

Path-only migration (ADR-0021 §4, Issue #151 §3) is the one recorded exception. During the repository restructure, an edit that changes only a file path, import or module path, current link, current or future command path, locator, CI/configuration path, test target path, or a section locator that moved with its file needs no superseding ADR. Such an edit never changes a decision, an invariant, a policy, an acceptance verdict, a domain contract or historical evidence.
