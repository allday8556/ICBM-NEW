# Permissions / Eligibility

| Platform | Status | Captured official fact |
| --- | --- | --- |
| SmartStore | REFER_TO_PLATFORM_LEDGER | ICBM SmartStore permission evidence remains authoritative; Commerce API has no OAuth scope list. |
| Coupang | OFFICIAL_CAPTURED | Open API key issuance and IP allowlist are seller/Wing controlled. |
| 11st | PARTIAL_OFFICIAL_CAPTURED | Seller must register/use 11ST Open API key; endpoint permission matrix not captured. |
| Kakao Shopping | OFFICIAL_CAPTURED | Not all sellers/integrators are eligible; integration review/contract is required. Gift API permission is separately granted. |
| Gmarket / Auction | OFFICIAL_CAPTURED | API access/permissions are approved per seller/tool/resource; auth success does not imply every resource is allowed. |
| LotteON | OFFICIAL_CAPTURED | APIs are split between public APIs and APIs usable only by specific partners. |
| SSG.COM | OFFICIAL_CAPTURED | EAPI is vendor/partner-facing and uses vendor authentication keys. |
